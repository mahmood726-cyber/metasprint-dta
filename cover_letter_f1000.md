We submit the manuscript **"Automated Open-Access Evidence Discovery for Diagnostic Test Accuracy Meta-Analysis: The MetaSprint DTA Platform"** as a Software Tool Article for *F1000Research*.

**The problem:** DTA meta-analysis requires specialised statistical methods (bivariate GLMM, HSROC) and manual evidence discovery is laborious. No existing tool combines automated open-access literature discovery with DTA-specific pooling in a zero-install format.

**Our solution:** MetaSprint DTA is a single-file browser application (28,857 lines) that integrates a 4-source open-access discovery pipeline (CT.gov, Europe PMC, OpenAlex, PubMed) with bivariate GLMM and HSROC meta-analysis. It features 70 pre-configured diagnostic topics across 13 medical specialties, transparent screening with extraction traceability, and living meta-analysis capabilities.

**Validation:** 70/70 diagnostic topics validated, 500 automated Selenium tests pass, 54 R parity tests (mada v0.5.12, metafor v4.8.0) with agreement within tolerance. 15 advanced methods include Cook's distance, Copas selection, profile likelihood, and DCA.

**F1000 fit:** This is a substantial, validated open-source software tool with transparent methodology — ideal for F1000's software tool article format with open peer review.

The manuscript has not been submitted elsewhere. Code is freely available.
